Capa de Extracción (ETL) y Multimodalidad

Motor usado para convertir documentos (PDF/PPT/Word) e imágenes a Markdown, y para transcribir audio/video, antes de vectorizar. Se aplica automáticamente en los 3 mecanismos de vectorización cuando la colección destino es híbrida.

Contextual Retrieval

Genera una cabecera contextual de 50-100 palabras por chunk antes de vectorizar, situándolo dentro de su documento completo para mejorar la recuperación. "Sin enriquecimiento" (por defecto) no agrega costo de LLM.

Cargando…

Indexación y Búsqueda Híbrida

Motores de embedding denso y disperso (BM25/BGE-M3) usados para indexar y para la búsqueda híbrida con fusión (RRF) en una sola llamada a Qdrant. Solo aplica a colecciones con esquema híbrido (vectores nombrados dense+sparse) — créalas desde Gestión Qdrant.

Reranking y Priorización

Reordena el Top-K recuperado por Qdrant a un Top-N hiperrelevante, aplicando un multiplicador de prioridad a los fragmentos etiquetados como "Material del curso" frente a la bibliografía complementaria.

Generador Final (LLM)

Modelo usado por el tutor para generar la respuesta final en "Pruebas del LLM", priorizando siempre el material del curso sobre la bibliografía complementaria.

Crea una nueva colección en Qdrant. Elige esquema híbrido (dense+sparse) para usar el pipeline RAG configurable, o legacy para compatibilidad con el flujo anterior.

API Reference — Gestión Qdrant

Endpoints de administración de colecciones expuestos por este servidor.

MétodoRutaDescripción
POST/api/collectionsCrea una colección (body: name, description, vector_schema, dense_size, distance)
GET/api/collections?detail=trueLista colecciones con esquema/puntos/estado
GET/api/collections/{name}Detalle de una colección
PATCH/api/collections/{name}Actualiza la descripción
DELETE/api/collections/{name}?force=boolElimina la colección
POST/api/collections/{name}/clearElimina todos los vectores, conserva el esquema
GET/api/collections/{name}/existsVerifica existencia
GET/api/collections/{name}/documentsLista documentos únicos vectorizados
DELETE/api/collections/{name}/documents/{filename}Elimina todos los chunks de un documento
GET/api/rag/retrieveRecuperación híbrida + rerank + boost, sin generación
POST/api/rag/answerPipeline completo del tutor (retrieve + rerank + boost + generación)
GET/api/config/{stage}Estrategia activa + catálogo de una etapa del pipeline RAG
POST/api/config/{stage}Cambia la estrategia activa de una etapa
